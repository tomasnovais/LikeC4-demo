Food Delivery Reference Architecture

A single model of UK food delivery: who is involved, what software they run, what information it holds, how that information moves, and who holds power over whom. Everyone knows how a takeaway reaches their door, so you can judge what a model like this shows.

This is a demo using the LikeC4 modelling language and the custom configuration and AI harness created by the WS3 team.

The content used in this demo (Food Delivery Example) is fully AI generated within the toolset mentioned and purely for capability demonstration purposes.

The product names are real, but the flows are simplified and every value is invented. It describes no named company's actual systems and it is not affiliated with any of them.

A suggested route

  1. Landscape / Index

    Overall view of the ecosystem. You can navigate to every detail from here.

  2. Follow One Order (in sequence mode)

    This view shows the step by step on how an order goes from being placed to being dropped off. Click the "Start" button on the top banner to follow for an additional feature.

  3. Capabilities

    Filtered view of the Capabilities that are required and what enables them.

  4. Open Questions and Assumptions

    Filter of all the elements with open questions and assumptions. If you open the element (top right icon in each box) you can click on the link and view the open question register.

  5. Delivery Platform System

    This view focuses on a particular system (aka a software solution type).

  6. Power Lens AKA "Neil's View"

    View of the power elements hold over each other. The relationships (arrows) hold illustrative data values of that power (e.g. fee %). These values come from a data file that can be linked to PowerBI or any other tool. This means we can have dashboards and this relationship model working from the same data source.

How to use it

Zoom icon, at the bottom of a box
Opens that system or subsystem.
Card icon, at the top right of a box
Opens its details, including any schema and links. Press Esc to close them.
Clicking a line
Shows its relationship data, wording and any schema. Click the empty canvas to close it.
Clicking a box
Only focuses it and dims the rest. Press Esc to clear that.
Ctrl + K
Searches for any view or element by name.
