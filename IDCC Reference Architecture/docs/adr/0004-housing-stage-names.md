# 0004. Housing stages are called "Scheme design" and "Construction", not "Development" and "Delivery"

- Status: accepted
- Date: 2026-11-03
- Deciders: Tomás Novais
- Affects: housing delivery lifecycle stage tags, GLOSSARY.md, all views filtered by stage

The housing delivery lifecycle's third and fifth stages are named **Scheme design** and **Construction**, although housing practice often calls them "development" and "delivery". "Development" already means a scheme in everyday housing use (we standardised on *scheme*) and is easily confused with the product lifecycle's *product development* stage; "delivery" is the name of the whole housing delivery lifecycle, so a stage called "Delivery" would make sentences like "data from delivery" ambiguous between one stage and all seven. The names are tags, so they can be changed later if a clearer pair is found, but the replacement must not collide with either of these terms.
