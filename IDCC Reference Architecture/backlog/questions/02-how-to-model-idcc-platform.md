# How is the IDCC platform modelled once it is designed?

- Type: open-question
- Status: needs-info
- Owner: Tomás Novais
- Affects: IDCC platform system (not yet modelled); IDCC-built software products; ADR 0005

IDCC may run a platform that hosts or links to the software it builds or controls centrally. It is deliberately left out of the pilot model so that views do not suggest a single "IDCC platform" for the whole pathway (ADR 0005). Once its scope is designed, decide: which software products it hosts or links to, whether it holds datasets of its own, and how hosting is recorded on those software products (the working proposal is metadata on each hosted software product).
