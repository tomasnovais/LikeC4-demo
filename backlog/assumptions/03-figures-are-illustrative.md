# Every figure in the model is illustrative

- Type: assumption
- Validation: open
- Owner: Tomás Novais
- Affects: `model/powerAndMoney.c4`; every relationship with a `transactionVolume`; ADR 0005

Commission rates, order volumes and fees are invented to be plausible and to show how such figures can be held in the model. None is a measurement, and none describes a named company. Before any figure is used to argue a point, it needs a real source.
