# Do platforms hold allergens as structured data or as free text?

- Type: open-question
- Status: needs-info
- Owner: Tomás Novais
- Affects: deliveryPlatformSystem.restaurantPortal.menus; fourteenAllergens; deliveryPlatformSystem

The example schemas list allergens as values from the 14 allergens. If a platform holds them only as free text in a dish description, the flow could not be checked against that standard, and the proposed menu update schema would need to change.
